# Лабораторные по Java

[English version](README.en.md)

Лабораторные по курсу программирования на Java, второй курс (сентябрь–декабрь 2023). Каждая папка `Java_N_M` это отдельная задача: N номер лабораторной, M номер задания.

| Лабораторные | Темы |
|---|---|
| 1 | Ввод и вывод, `Scanner` |
| 2 | Классы и объекты: автор, мяч, точка и окружность, магазин, собака и питомник, книжная полка, раздача покера |
| 3 | `ArrayList`, `Collections.sort`, `Random`, форматирование строк (отчёт по сотрудникам) |
| 4 | Наследование и абстрактные классы: иерархия одежды для ателье, фигуры (круг, прямоугольник, квадрат), книги и читатель |
| 5, 12 | Графика на Swing: рисование случайных фигур в `JFrame` |
| 6 | Интерфейсы: перемещаемые фигуры (`Movable`), конвертеры температуры |
| 7 | Функциональные интерфейсы и обработка строк |
| 8 | Рекурсия |
| 9, 10 | Сортировки массива студентов, `Comparable` и `Comparator` |
| 11 | Даты: `Date`, `Calendar`, `SimpleDateFormat` |
| 13, 14 | Строки и регулярные выражения: форматирование телефонов, проверка адресов почты |
| 15, 16 | Оконные приложения на Swing: кнопки, обработчики событий, мышь, поле пароля, работа с файлами |

Папка `Java_early_2023` содержит первые версии лабораторных 2.1–2.7 (октябрь 2023) в виде проекта IntelliJ с пакетами `labs.forlaba2.*`. Позже эти задачи вошли в общий набор в папках `Java_2_*`.

## Запуск

```bash
cd Java_2_7/src
javac *.java && java BookTest
```

## Стек

Java, Swing, IntelliJ IDEA.
