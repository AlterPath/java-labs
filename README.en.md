# Java Labs

[Русская версия](README.md)

Lab assignments for a Java programming course, second year (September–December 2023). Each `Java_N_M` folder is one task: N is the lab number, M is the task number.

| Labs | Topics |
|---|---|
| 1 | Input and output, `Scanner` |
| 2 | Classes and objects: author, ball, point and circle, shop, dog and kennel, bookshelf, poker dealing |
| 3 | `ArrayList`, `Collections.sort`, `Random`, string formatting (an employee report) |
| 4 | Inheritance and abstract classes: a clothing hierarchy for a tailor shop, shapes (circle, rectangle, square), books and a reader |
| 5, 12 | Swing graphics: drawing random shapes in a `JFrame` |
| 6 | Interfaces: movable shapes (`Movable`), temperature converters |
| 7 | Functional interfaces and string processing |
| 8 | Recursion |
| 9, 10 | Sorting an array of students, `Comparable` and `Comparator` |
| 11 | Dates: `Date`, `Calendar`, `SimpleDateFormat` |
| 13, 14 | Strings and regular expressions: phone formatting, email validation |
| 15, 16 | Swing desktop apps: buttons, event handlers, mouse, a password field, working with files |

The `Java_early_2023` folder holds the first versions of labs 2.1–2.7 (October 2023) as an IntelliJ project with `labs.forlaba2.*` packages. Later these tasks went into the main set in the `Java_2_*` folders.

## Quick start

```bash
cd Java_2_7/src
javac *.java && java BookTest
```

## Tech stack

Java, Swing, IntelliJ IDEA.
